# Rahul Taritla · Portfolio

Personal site: https://rahulbunny07.github.io/my-portfolio/

Built with React 18, TypeScript, Vite, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173/my-portfolio/

## Deploy

```bash
npm run deploy
```

Builds the site and publishes `dist/` to the `gh-pages` branch.

## Editing content

All text (stats, case studies, experience, skills) lives in `src/data/content.ts`.
The resume served by the site is `public/Rahul_Taritla_Resume.pdf`.
